AI Voice Testing

Pod: Daniel Puerta, Adrian Gutierrez Rodriguez
Updated: 2026-11-23 · Status: Ready for PRD
Automated voice agent testing that hears what chat tests can't — catch pronunciation, timing, and conversational defects at 10× the volume before customers do.

Problem

  • Human bottleneck on voice evaluation — every voice response must be heard by a person; caps test volume at a handful of calls per change
  • Chat tests miss voice defects — text-based alternatives look fine on screen but miss pronunciation, timing, cadence, tone
  • Edge cases go untested — human-on-call requirement leaves adversarial scenarios uncovered until production
Solved today by

Manual phone calls, Connect chat tester (text only), post-hoc transcript/log review, CloudWatch + LLM via Miro, early DeepEval adoption (not voice-native)

Solution

  • Scenario generator — from Connect flow definitions, transcripts, KB content
  • Eval runner — direct API calls; Gemini for audio, Bedrock for text
  • Voice quality scorer — Gemini API on audio for pronunciation, cadence, tone, timing
  • Scorecard & reporting — unified pass/fail dashboard with regression tracking
  • Human eval UI — per-turn defect flagging on transcriptions; baselines + calibration

Unique value proposition

One automated framework to generate, execute, and score voice agent tests at scale — so teams catch pronunciation, timing, and conversational defects before customers hear them.

Customer

Ship voice agents with confidence. Cover edge cases manual testing misses. Catch regressions before callers hear them.

Slalom

Faster delivery on Connect engagements + differentiated offering competitors don't have. Win-rate lever for pursuits.

Differentiation

  • Voice-native evaluation — evaluates real audio, not just text
  • End-to-end orchestration — scenario generation → execution → scoring → reporting
  • Platform-extensible — Connect first; adapters for Genesys, Twilio later
  • Human-calibrated scoring — eval UI produces ongoing baselines
  • Slalom delivery moat — expertise accumulates in the framework design, not shared data

Customer segments

Users: Dev leads and engineers building voice agents in Amazon Connect

Buyers: Engineering managers and contact center leaders at enterprises

Beneficiaries: Customer teams (release confidence), Slalom (delivery speed + win rate)

  • Connect chat tester — text only

Positioning: orchestration layer that consumes these tools, not a competitor
